Mediana calculada métrica a métrica entre as execuções de cada rótulo
(req/s e p95 de uma mesma linha podem vir de execuções diferentes).
cpu_ms_req_banco = CPU banco % x 10 / req/s
cpu_ms_req_total = (CPU banco % + CPU API %) x 10 / req/s
As duas são calculadas por execução e depois tira-se a mediana.
ram_* = memória média do container (inclui cache de páginas; varia entre execuções).
